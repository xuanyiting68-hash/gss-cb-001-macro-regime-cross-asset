# Instructions for research agents

Before doing work, read `docs/CURRENT_STATE.md`, `docs/RESEARCH_PROTOCOL.md`, `docs/PAPER_FIREWALL.md`, `docs/EVIDENCE_LEDGER.csv`, and the relevant public research protocol.

- Treat this repository as the public PandaAI / macro-research / social-media companion, not the unpublished academic-paper repository.
- Preserve null results, failed hypotheses, negative OOS results and identification limitations.
- Do not tune thresholds, horizons, samples or transformations after seeing outcomes to manufacture significance.
- Use point-in-time / release-time information when a forecasting or policy-information claim requires it.
- Distinguish realized FOMC actions from identified monetary-policy shocks.
- Apply declared multiple-testing corrections; raw p-values are not enough.
- A forecasting claim requires time-ordered OOS evidence.
- A trading/deployment claim additionally requires realistic timing, costs, turnover, drawdown and adverse-excursion analysis.
- Clearly label exploratory results as QUARANTINED or HYPOTHESIS-GENERATING.
- Never turn a descriptive association into causal language.

Do not commit private-paper staff forecast paths, private reaction-function panels, unpublished private-paper regressions, secrets, personal data, or redistribution-uncertain raw vendor data.

The owner authorizes QC-passed public-safe research artifacts to be committed to main without per-file approval. For each milestone, update the current state, evidence ledger, changelog and file manifest, then read GitHub back to verify the commit.
