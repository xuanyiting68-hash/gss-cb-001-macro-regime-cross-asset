The private repository was read from the latest main state before this audit. The public repository was empty before initialization.

## What the private project already has that is useful publicly

1. **Evidence discipline** — descriptive, associational, mechanism and causal claims are separated.
2. **Point-in-time/source timing** — directly useful for PandaAI forecasts, regime monitors and policy-state dashboards.
3. **Falsification-first workflow** — preserves nulls instead of searching for a better story.
4. **Shock-type separation** — rerouting cost, quantity loss and risk-premium mechanisms should not be pooled naively.
5. **Event-state bridge logic** — recent geopolitical episodes remain descriptive unless identification is stronger.
6. **Evidence-ledger / manifest / handoff structure** — excellent infrastructure for a long-running public research project.

## What should not be transferred from the private paper

Do not transfer exact staff FFR paths, the frozen private reaction panel, exact-source meeting registries, unpublished C0/C1 paper diagnostics, Tealbook/Greenbook source files, or other private/unreleased paper artifacts.

## What PandaAI/public work can add without contaminating the paper

- Fed-cycle path, drawdown, volatility and recovery analytics.
- P0-A audit as a methods case study: replication is not statistical validity.
- Household-inflation / crack-spread research.
- Commodity-reversal state-machine research.
- Public cross-asset dashboards.
- Social-media content whose claims inherit evidence labels.

## Recommended architecture

Private paper:
`Fed reaction / expected persistence / policy conditioning`

Public companion:
`Macro state / Fed cycle / cross-asset risk paths / household inflation / commodity turning points / PandaAI / social media`

The two projects should share research discipline, not unpublished empirical artifacts.
