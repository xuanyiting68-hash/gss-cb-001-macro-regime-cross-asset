# Fed Cycle × Cross-Asset Investor Knowledge Atlas — 032

## 最重要的五个认识

### 1. “政策动作”与“市场路径”不是同一个时钟

FIRST_HIKE 后3个月，S&P 500 / Nasdaq 中位数为 -2.6% / -6.2%，但12个月变为 +8.0% / +6.5%。市场可以在紧缩开始后先承压、随后仍以正的12个月终点结束。

### 2. 最后一次加息与暂停阶段，市场收益率可以先于官方降息明显下降

LAST_HIKE 后2Y/10Y 12个月中位下降 124.6bp / 59.9bp；PAUSE_START 后进一步下降 127.9bp / 107.5bp。与此同时机械现金carry仍约 +5.9% / +5.9%。所以“债券市场先宽松、现金carry仍高”可以同时存在。

### 3. FIRST_CUT最需要看路径风险，而不是只看一年后收益

S&P 500 / Nasdaq FIRST_CUT 12个月中位仍为 +11.0% / +6.0%，但MDD达到 14.0% / 17.5%，低点月中位都在M8。WTI更弱：12个月 -16.9%、MDD 22.2%、低点M11。

### 4. 首降附近的压力层经常仍在发展

FIRST_CUT 窗口的Baa压力峰值月中位M7、VIX M8、铜 M9。这解释了为什么“Fed开始降息”和“风险已经结束”不是同义词；但这些峰值是事后统计，不能拿来做实时底部日期。

### 5. 资产覆盖越广，越要尊重证据等级

五个核心资产可以做四阶段描述；房价是慢变量；亚洲股市只能做诊断异质性；BTC/TLT/VNQ当前样本过短。最容易犯的错误不是少算一个指标，而是把不同证据等级的结果写成同样确定。

## 延伸资产：现在能说到什么程度

- **TLT：LIMITED_SAMPLE。** FIRST_CUT 12M中位 +15.1%，但仅3个样本量级。
- **VNQ：LIMITED_SAMPLE。** PAUSE 12M中位 +23.5%，FIRST_HIKE -17.8%；不能建立稳定REIT周期规律。
- **BTC：LIMITED_SAMPLE。** PAUSE 12M中位 +116.7%，FIRST_HIKE -38.4%；只有2个episode，幅度不能替代证据量。
- **美国房价：SUPPORTED_SLOW_MOVING。** FIRST_CUT 后12/24M中位约 +5.2% / +12.7%，但其风险口径是24M decline，不是股票MDD。
- **亚洲股市：DIAGNOSTIC_ONLY。** FIRST_CUT 12M中位：Hang Seng -8.7%、KOSPI +4.3%、Nikkei +9.6%、Shanghai -28.7%，异质性明显。

## 对后续研究最有价值的缺口

1. TLT/VNQ/BTC需要更长的可比历史或底层指数替代，当前不能升级证据等级。
2. 房价需要单独研究利率→按揭成本→成交→价格的滞后链，而不是套股票时钟。
3. 亚洲资产需要加入本地政策、美元和信用变量，不能只用Fed阶段解释。
4. Gold还可以进一步拆解实际利率、美元、通胀预期、风险压力的阶段贡献，但必须另立研究设计。
5. 当前2026周期应继续用append-only实时状态，而不是把历史阶段中位数直接变成预测。

## 投资认知边界

这个Atlas告诉我们“历史上不同阶段出现过什么分布和路径”，不是告诉我们“今天应该买什么”。真正可用的框架是：政策阶段 + 市场利率 + 现金carry + 压力层 + 资产自身历史路径 + support strength + 当前数据 freshness。
