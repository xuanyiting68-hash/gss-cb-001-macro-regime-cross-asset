# 新聊天接续指令 — Public PandaAI / Macro Research

https://github.com/xuanyiting68-hash/gss-cb-001-macro-regime-cross-asset

这是 PandaAI / 宏观周期认知 / 跨资产 / 社交媒体赋能的公开研究仓库，不是未发表学术论文的 canonical 私有仓库。

开始前：

1. 读取最新 main。
2. 先读 README.md、AGENTS.md、docs/CURRENT_STATE.md、docs/RESEARCH_PROTOCOL.md、docs/PAPER_FIREWALL.md、docs/EVIDENCE_LEDGER.csv。
3. 再读取当前任务对应的 research protocol、results、source/provenance 和 changelog。
4. 以 GitHub 当前状态为准，不要根据旧聊天摘要重新做已经完成的工作。

研究要求：

- 真实运行研究和 QC，不只给方案。
- 保留空结果和失败假设，不追显著性。
- 严格区分 descriptive / association / mechanism / causal。
- FOMC HIKE/HOLD/CUT 不等于 identified monetary-policy shock。
- 预测研究必须 time-ordered OOS。
- 多重检验必须使用声明的 family。
- 商品反转不能用“价格高了就空”；必须区分 supply normalization、demand destruction 与 false relief。
- 社媒内容必须继承底层研究的 evidence status，不能把 exploratory 结果写成确定规律。
- 不上传 API key、个人隐私、受限数据、redistribution 权限不清的 vendor raw data。
- 不把私有论文里的 exact staff paths、private reaction panel、S6D.3 unpublished results 搬进公开仓库。

GitHub 同步：

当研究输出通过 QC，或形成对复现/接续有用的 public-safe protocol、code、derived table、figure、provenance 或 content 时，直接同步到 main，无需逐项询问。
